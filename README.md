# Tickets-App
4.0.0

## 新功能
- 票据搜索与智能排序
- 收藏票据与即将到来分类
- 自动归档
- JSON 导入 / 导出与备份恢复
- 二维码 / 条形码识别
- 普通票据后台提醒
- Android「闹钟和提醒」权限支持
- 重启 / App 更新后的提醒恢复
- FCM 提醒
- FCM 实时通知
- 深色自定义弹窗
- Live Update与小米超级岛持续优化，新支持三星实时窗通道可供选择

## 优化
- 优化票据输入和编辑体验
- 优化截图识别与在线识别配置
- 优化后台处理和大量票据场景性能
- 减少重复刷新和不必要计算

## 说明
FCM 默认关闭，可在设置中单独开启。
普通票据提醒与 FCM 相互独立。
