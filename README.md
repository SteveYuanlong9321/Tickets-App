# Tickets-App
Tickets · 票据

一个面向 Android 的本地票据管理应用，支持电影票、车票、机票、演出/门票、取餐码和取件码票据类型。

当前版本
# 票据 5.0.0

## 新增功能

### 二维码 / 条形码
- 新增二维码 / 条形码录入。
- 新增二维码 / 条形码类型选择。
- 新增相机扫码功能。
- 支持在票据详情页直接展示二维码 / 条形码。
- 图片、PDF 智能识别时支持提取二维码 / 条形码信息。

### 票夹视图
- 移除网格视图。
- 保留列表视图与堆叠视图。
- 堆叠视图采用 Wallet 风格展示。
- 优化票据卡片上下滑动交互。
- 修复堆叠视图下票据可能无法显示的问题。

### 票据详情
- 完善机票、火车票、电影票、活动票、门票、取餐码、取件码等票据详情字段。
- 根据不同票种显示对应的信息。
- 机票增加起飞、降落、出发登机口、到达登机口等可选信息。
- 活动票、门票增加场地、区域、座位、入场等信息。
