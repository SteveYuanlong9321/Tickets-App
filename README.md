# Tickets-App
3.0.0
票据类型与信息填写
新增「取餐码」和「取件码」票据类型。
完善取餐码、取件码的信息字段与填写逻辑。
取餐码时间改为选填，未填写时间也可以正常保存。
车票新增「出发站台」「到达站台」字段。
机票新增「出发口」「到达口」字段。
所有必填字段统一使用 * 标记，选填字段不再额外添加括号提示。
智能识别
智能识别分为「离线识别」和「在线识别」。
在线识别支持选择 AI 平台、模型以及自定义 API Key。
完善自定义提示词功能，并按照 App 实际票据字段重新整理识别规则。
优化 DeepSeek 模型名称显示。
LiveUpdate 与小米超级岛
完善电影票、车票、机票、取餐码、取件码等票据的实时通知展示。
取餐码和取件码支持全天实时展示。
取餐码与取件码增加对应操作按钮：
取餐码：「我已取餐」
取件码：「我已取件」
点击对应按钮即可直接将票据标记为已使用并销毁实时通知卡片。
机票、取餐码、取件码的通知图标及展示效果进一步优化。
取餐码通知图标支持根据票据品牌显示对应图标，并保持原始比例。
票据状态管理
所有票据详情页新增「标为已使用」功能。
已使用票据会归入「已过期」分类。
「标为已使用」支持切换为「标记为未使用」，恢复后票据重新正常展示。
已使用状态支持本地持久化。
标记为已使用后会停止对应的实时通知、提醒及超级岛展示。
更新日志与关于
更新日志改为版本列表形式。
最新版本显示在最上方。
点击版本号后进入对应版本的详细更新信息。
优化更新日志页面返回层级。
性能与体验
优化票夹、添加票据、编辑票据、删除票据等页面切换体验。
优化大量票据情况下的列表与网格加载方式，减少不必要的重复渲染。
优先让 UI 响应，再进行保存、提醒及系统通知等后续处理。
优化票据保存时的本地数据处理，减少主线程负担。
优化页面转场动画，使页面切换更加流畅、灵敏。
减少删除或保存票据时的卡顿和黑屏现象。
整体降低不必要的 CPU 负担，改善长时间使用时的流畅度与发热表现。
其它
App 版本统一更新为 3.0.0。
